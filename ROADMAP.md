# AURA — Roadmap

Кроссплатформенный мессенджер со сквозным шифрованием (Web, Android, iOS) на Flutter.
Личный проект, до 20–30 пользователей онлайн.

- Дизайн: https://claude.ai/artifact/WtBLaG5DtxkVA1fVTxMwJ8
- Дизайн-система: https://claude.ai/artifact/WLmUZJx5LKwhhWQUZMoKMh

## Решения

| Что | Выбор |
| --- | --- |
| Клиент | Flutter (Web, Android, iOS), один код |
| Сервер | Dart: shelf + WebSocket |
| База | SQLite (WAL). Переход на PostgreSQL, если сервер станет многоэкземплярным или онлайн вырастет до сотен |
| Шифрование | Signal Protocol (X3DH + Double Ratchet), `libsignal_protocol_dart` |
| Хостинг | Свой сервер в Docker, доступ из интернета через Cloudflare Tunnel (Zero Trust) |
| Сборка | GitHub Actions: Web, Android, iOS (iOS без подписи до появления Apple Developer аккаунта) |

## Структура репозитория

```
app/      Flutter-клиент
server/   Dart-сервер
.github/  CI
```

## Этап 1. Каркас приложения на трёх платформах

- [x] Flutter-проект в `app/`, сборка под Web, Android, iOS
- [x] Тема из дизайн-системы: Comfortaa + Ubuntu, палитра, светлая и тёмная тема
- [x] Экраны на тестовых данных: Приветствие, Вход, Регистрация, Чаты, Диалог, Настройки, Профиль
- [x] GitHub Actions собирает все три платформы

Готово, когда: приложение открывается в браузере, на Android и iOS, по экранам можно пройти.

## Этап 2. Сервер и живая переписка

- [x] Dart-сервер в `server/`: регистрация, вход, сессии
- [x] Доставка сообщений 1-на-1 через WebSocket, очередь для офлайн-получателей
- [x] SQLite: пользователи, сессии, очередь сообщений
- [x] Dockerfile и запуск через Cloudflare Tunnel на вашем домене
- [x] Экран Контакты: собеседники из переписки, новый находится только по точному никнейму

Готово, когда: два человека на разных платформах переписываются через ваш сервер. Шифрование пока только транспортное (HTTPS).

## Этап 3. Сквозное шифрование

- [x] Android ходит только по HTTPS через туннель (`aura.cir-matrix.space`), HTTP запрещён
- [x] Ключи устройства: identity key, signed prekey, one-time prekeys; приватные ключи только на устройстве
- [x] Сервер хранит и выдаёт публичные prekey bundles
- [x] X3DH для установки сессии, Double Ratchet для сообщений
- [x] Сервер видит только зашифрованный текст
- [x] Сверка кода безопасности собеседника
- [x] Биометрическая блокировка приложения (Android, iOS; в браузере её нет)
- [x] ~~Web-вход по QR~~ Каждое устройство (телефон, браузер) входит по паролю и получает свои ключи; сообщения шифруются для каждого устройства собеседника и копией для своих. История на новое устройство не переносится

Готово, когда: в базе сервера нет ни одного открытого текста сообщения.

## Этап 4. Медиафайлы

- [ ] Файл шифруется на клиенте случайным ключом, ключ уходит внутри E2E-сообщения
- [ ] Сервер хранит зашифрованные файлы на диске
- [ ] Фото, видео, документы, голосовые; превью

## Этап 5. Групповые чаты

- [ ] Группы поверх попарных Signal-сессий (sender keys)
